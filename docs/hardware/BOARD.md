## 后续核验

1. 内存：取得匹配料号的原厂手册，或读 DDR/U-Boot 启动日志及 Linux `/proc/meminfo`。Linux 可用内存会受保留区域影响。
2. SKU：以购买订单、板背标签或板厂对应 BOM 确认；官网四款配置只是目录快照，不代表当前实物。
3. 固件：登录后记录系统、设备树、MMC 类型和容量；当前已下载镜像尚未证明适配本板。
4. 首次刷写前备份现有内容，核对 DDR、板级版本、分区总大小及 8 GB eMMC 容量；现有分区表不等于完整备份。
